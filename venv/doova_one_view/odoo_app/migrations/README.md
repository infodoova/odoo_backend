# Database Migrations

This directory contains the history of database schema changes for the `odoo_app`.

## 🛠 Usage

These files are automatically generated by Django when running:
```bash
python manage.py makemigrations
```
And applied using:
```bash
python manage.py migrate
```

## ⚠️ Important

- **Never** manually edit these files unless absolutely necessary for complex data migrations.
- Always review migrations before applying them to production to ensure index creation and column constraints are correct.
- Ensure `tenant_id` columns and indexes are included in new analytics tables.
