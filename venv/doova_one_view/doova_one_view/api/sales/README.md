# Sales Module

Handles sales orders, customer interactions, and revenue tracking.

## 📁 Structure

- **`routes.py`**: Endpoints for sales orders and quotations.
- **`schemas.py`**: Models for sales data.
- **`service.py`**: Business logic for sales cycles and revenue aggregation.

## 💰 Key Features

- Sales Order (SO) management.
- Customer sales history.
- Revenue reporting.
- Integration with accounting for invoicing.
