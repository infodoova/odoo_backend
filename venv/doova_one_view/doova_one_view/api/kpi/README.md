# KPI Module

Calculates and serves Key Performance Indicators (KPIs) for business analysis.

## 📁 Structure

- **`routes.py`**: Endpoints for retrieving KPI data (Sales, Profit, etc.).
- **`schemas.py`**: Models for KPI values and time-series data.
- **`service.py`**: Complex logic for aggregating data and calculating metrics.

## 📊 Key Features

- Dashboard metric calculation.
- Historical trend analysis.
- Tenant-specific business performance tracking.
