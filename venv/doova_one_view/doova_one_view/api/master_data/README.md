# Master Data Module

Manages core business entities that are shared across different modules, such as Partners (Customers/Vendors), Companies, and Currencies.

## 📁 Structure

- **`routes.py`**: Endpoints for CRUD operations on master data.
- **`schemas.py`**: Pydantic models for core entities.
- **`service.py`**: Logic for managing master data records.

## 🔑 Key Features

- Customer and Vendor management.
- Multi-currency support and exchange rates.
- Company profiles and organizational structure.
