# Inventory Module

Handles stock, products, and inventory-related operations.

## 📁 Structure

- **`routes.py`**: Endpoints for querying stock levels, products, and stock moves.
- **`schemas.py`**: Pydantic models for product and inventory data.
- **`service.py`**: Logic for stock calculation and inventory tracking.

## 📦 Key Features

- Product catalog management.
- Real-time stock level queries.
- Tracking of stock movements (receipts, deliveries, internal transfers).
- Inventory valuation data.
