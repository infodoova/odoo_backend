# Files Module

Manages file uploads, storage, and retrieval within the system.

## 📁 Structure

- **`routes.py`**: Endpoints for uploading, downloading, and listing files.
- **`service.py`**: Logic for storage interaction, file naming, and metadata management.

## 📁 Key Features

- Secure file uploads (e.g., CSVs for Odoo data).
- File storage abstraction.
- Retrieval of stored files by ID or path.
- Integration with tenant-specific storage paths.
