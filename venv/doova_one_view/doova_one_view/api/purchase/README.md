# Purchase Module

Manages procurement processes, including purchase orders and vendor interactions.

## 📁 Structure

- **`routes.py`**: Endpoints for purchase orders and lines.
- **`schemas.py`**: Models for purchasing data.
- **`service.py`**: Business logic for procurement workflows.

## 🛒 Key Features

- Purchase Order (PO) tracking.
- Vendor performance data.
- Integration with inventory for received goods.
