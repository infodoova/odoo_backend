# Accounting Module

This module handles accounting data and operations, providing endpoints for retrieving financial records such as invoices, payments, and account moves.

## 📁 Structure

- **`routes.py`**: API endpoints for accounting operations.
- **`schemas.py`**: Pydantic models for request/response validation.
- **`service.py`**: Business logic and data access layer for accounting records.

## 🚀 Key Features

- Fetching and filtering invoices and bills.
- Retrieving account move details.
- Financial data aggregation for reporting and dashboards.
- Integration with Odoo accounting entities.
