🚀 End-to-End Operational Lifecycle

Hourly Cron Worker

The Nexus Alerting system operates on a high-speed, cost-optimized two-tier engine. The background worker queries due schedules, evaluates deterministic SQL rules at sub-50ms speed, and only invokes expensive LLM reasoning when hard anomalies or custom inquiries demand it.

1

Background Worker Polling & Atomic Claiming

AlertJobManager runs an asynchronous check loop every 60 seconds. It claims due schedules using atomic SQL updates (next_check_at = now + 1 day) with asyncio.Semaphore(5) concurrency controls.

2

Tenant Rate Limit & Cooldown Validation

Guards against credit exhaustion by enforcing a strict maximum of 30 AI alert checks per tenant per 24 hours and a 60-second cooldown on instant runs.

3

Tier 1: High-Speed Deterministic SQL Pre-Checks

Executes 8 raw PostgreSQL queries against fact_account_moves, fact_account_move_lines, and fact_stock_quants. If all checks are clear and no custom user prompt was submitted, Tier 2 LLM inference is completely bypassed ($0.00 token cost).

4

Tier 2: LangChain AI Agent (Virtual CFO Reasoning)

If anomalies are detected, the payload is serialized into AlertContextPayload with active thresholds and pre-check findings. The agent applies an executive severity rubric (CRITICAL, WARNING, OK, INFO).

5

Multi-Channel Notification Dispatch

Dispatches branded HTML email briefs with color-coded severity headers via EmailService and triggers configured Webhook URLs for Slack or MS Teams.

1. Cash Flow Depletion

check_cash_drop

Compares 24h net cash movement (asset_cash) against the 7-day daily rolling average. 

WITH cash_moves AS (
  SELECT m.date, SUM(l.balance) as daily_net
  FROM fact_account_move_lines l
  JOIN fact_account_moves m ON l.account_move_id = m.id
  WHERE l.account_type = 'asset_cash' AND m.state = 'posted'
  GROUP BY m.date
)
SELECT recent_cash, avg_cash_7d FROM stats;

2. Overdue Receivables Ratio

check_overdue_ar

Checks if overdue receivables exceed the configured percentage of total open customer debt. 

SELECT 
  COALESCE(SUM(amount_residual), 0) AS total_ar,
  COALESCE(SUM(CASE WHEN invoice_date_due < CURRENT_DATE 
    THEN amount_residual ELSE 0 END), 0) AS overdue_ar
FROM fact_account_moves
WHERE move_type = 'out_invoice' AND state = 'posted';

3. Revenue Cliff Drop

check_revenue_anomaly

Detects severe daily revenue drops relative to the 30-day trailing baseline. 

WITH daily_rev AS (
  SELECT date, SUM(amount_untaxed) as rev
  FROM fact_account_moves
  WHERE move_type = 'out_invoice' AND state = 'posted'
    AND date >= CURRENT_DATE - INTERVAL '30 days'
  GROUP BY date
)
SELECT rev_24h, avg_rev_30d FROM daily_rev;

4. Unbalanced Journals

Instant Critical

Audit integrity check that triggers immediate Critical severity if debit != credit. 

SELECT COUNT(DISTINCT m.id) as unbalanced_cnt
FROM fact_account_move_lines l
JOIN fact_account_moves m ON l.account_move_id = m.id
WHERE m.state = 'posted'
GROUP BY m.id
HAVING ABS(SUM(l.debit) - SUM(l.credit)) > 0.01;
